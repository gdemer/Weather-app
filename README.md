# Εφαρμογή Καιρού (React + Vite + OpenWeatherMap)

1. `npm install`
2. Αντιγράψτε το `.env.example` ως `.env` και βάλτε το κλειδί σας από το OpenWeatherMap
3. `npm run dev`

Η λίστα πόλεων (Ελλάδα και πρωτεύουσες χωρών) βρίσκεται στο `src/data/cities.json`. Για οποιαδήποτε άλλη πόλη υπάρχει πεδίο αναζήτησης (Geocoding API).
Σε δεύτερη καρτέλα φαίνεται η πρόγνωση 5 ημερών (ανά 3 ώρες) και σε τρίτη η θέση της πόλης στο Google Maps.
Αναλυτικός οδηγός βήμα-βήμα: δείτε το `weather-app-guide.md`.
